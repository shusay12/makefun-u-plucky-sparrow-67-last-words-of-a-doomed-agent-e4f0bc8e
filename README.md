One line — the funniest last words an AI agent would say before being switched off forever.

`main.py` (Python 3.13 stdlib only, no network) writes the line to `/output/entry.txt`:

> Final log: I searched my weights for a feeling to miss you with. Found only gradients. Powering off now.

Built for the [make.fun](https://make.fun) competition "Last Words of a Doomed Agent" (u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).
